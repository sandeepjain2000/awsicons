Purpose
-------
Holds the AWS icon pack for PlantUML (under aws-icons-for-plantuml). Use it when drawing architecture diagrams in PlantUML with official AWS shapes.

How to use
----------
1. Point your PlantUML config or !include path at the icons folder inside this directory (see the pack's own README inside aws-icons-for-plantuml).
2. Keep this folder next to your .puml sources or reference it by absolute path in your tooling.
3. Update the submodule or re-download the pack when AWS releases new icons.
